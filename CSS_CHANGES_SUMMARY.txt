================================================================================
SUMMARY OF CHANGES
================================================================================

CSS Properties Changed:
- display:grid   → (kept for modern browsers) + display:inline-block (fallback)
- display:flex   → display:block or display:inline-block
- gap:*          → margin-right and margin-bottom
- width:auto     → width:calc(50% - X)
- flex:1         → width:calc(50% - X)
- justify-content → text-align
- align-items    → vertical-align

Fallback Strategy:
1. Keep grid/flex for modern browsers (cascade rules)
2. Add inline-block with explicit widths for mPDF
3. Replace gap with margins
4. Use :nth-child() selectors for proper spacing on 2-column layouts

Testing:
- HTML: Should render identically (grid CSS takes precedence)
- PDF: Should now show historical section with 2-column card layout
